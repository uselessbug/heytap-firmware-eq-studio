# 桌面固件编辑（2026-10-10）

当前统一工作区及参考差分流程见 [说明](unified-workspace.md)。

已接入经过完整代码指纹和指针表确认的 Enco X4 固件。未知布局仍可检查和扫描；需要先确认参数语义才能写入。

1. 打开固件，导入或生成当前修正 EQ。
2. 点击“拟合到固件预设”，选择替换预设和整体衰减。基底为当前选中预设对应的各路径／状态，普通预设处理四条路径 × 九个内部状态，共 36 条记录；特殊配置按实际记录集合处理，当前为四条；保留基线 HP/LP/AP，容量最多 18 个滤波器。
3. 拟合在后台执行，可取消。可以为多个预设准备不同修正；修改当前外部 EQ 不会改变已准备的预设快照，同名预设重新拟合会替换旧计划。数字图可比较原固件链与待导出链。
4. 点击“编辑固件信息”。软件版本同步容器、SW_VER 和重新核对的 12 字节 Thumb getter；其余已知容器字段、各构建段的 BUILD_DATE/REV_INFO 可按字段容量编辑。结构地址、长度和校验自动管理。
5. 点击“导出固件”，查看三采样率最差误差，并设置允许 RMS/最大误差。默认 0.45/1.5 dB；你可以按实际用途调整。导出时按 float32 写入值重算，不信任计划中的报告值。
6. 选择新文件名。原输入不覆盖；输出重新解包校验，检查只改计划记录/元数据字段，并生成旁边的 .report.json。工程 v4 保存拟合计划和元数据修改，支持撤销重做、自动恢复，兼容 v1/v2/v3。

拟合误差指标覆盖各路径峰值下 30 dB 内的有效频段，另外保留全频段 RMS。模型是数字滤波幅度近似；实机 OTA 接受、双单元声学叠加及听感仍需实际验证。修改丹拿原声还会改变未知内部状态回退到索引 8 的响应；特殊配置有独立选择与写入入口，不随普通预设一起修改。
