# 统一调音工作区

主图同时显示相对频响与数字滤波增益；频率轴、游标和缩放共用。左轴以 dB 表示相对声压／EQ 增益。关闭“相对声压”后，右轴显示由原始测量电平偏移得到的 SPL，两个轴保持相同 dB 比例。目标按 1 kHz 对齐，编辑和曲线显隐保留视野。

## 使用流程

1. 打开固件，在唯一的预设按钮组选择调音基底。DAC1（输出1）、DAC2（输出2）是显示别名，物理 DAC 编号尚未完全确认。复选框支持同时叠加两路，且不控制写入范围。
2. 原始频响卡片直接选择来源、品牌、型号、测量条件；型号选定后自动载入。目标卡片可搜索在线目标库、导入文件，或把当前选中测量设为目标。首次依据已识别设备尝试唯一匹配，此后按设备记忆。
3. 如需导入固件相对测量固件的差分，点击“选择参考固件”，选择测量对应的原固件与预设。内部状态、参考状态、区域、采样率和模型设置位于“计算详情”。测量来源未声明准确对应关系时，保留“参考关系为假定”。
4. 调整 PEQ／RAW，或生成修正 EQ。生成修正时以当前固件估计为原始响应（如果已绑定参考）；现有修正被整体替换，可以撤销。
5. 拟合到目标固件预设，基底使用当前选中配置。操作覆盖所有输出、区域和对应状态，保留基底 HP／LP／AP。原版 Enco X4 的普通预设为四表×九状态，共 36 条；特殊配置为四条。生成后，橙色虚线和 DAC 虚线使用待写入的 float32 滤波器。最后导出新固件。

“当前固件估计”对应打开的输入固件；“编辑后估计”在其上应用当前修正；“待导出估计”来自准备好的写入计划。计划保存自己的 EQ 快照，可以同时为不同目标预设准备调音。

## 差分模型

每路比较当前／参考数字滤波器的复数传递函数。两路比值在幅度和相位上均相同，使用共同传递变化；仅幅度相同不能证明这一关系。

两路变化不同时，当前提供互补功率权重模型：DAC1 权重 `1-w`，DAC2 权重 `w=1/(1+(fc/f)^8)`。默认交接频率 15 kHz，可修改。这是单元贡献与非相干叠加的假设，不是从整机幅度测量恢复出的实际单元声学响应。图中标出 `fc/1.4..fc*1.4` 的近似交叠区域。已有独立单元与相对相位测量时，应使用对应声学模型替换它。

默认差分仅计算滤波器；gain0/gain1 有变化时明确提示未折算。可以选择假定按 gain0 或 gain1 计入整体增益，但不会将两个字段直接相加。

已内置原版 112／116 的参考 EQ 参数模板（两版参数相同），识别 Enco X4 后默认绑定丹拿原声并标为“参考关系为假定”。如果测量条件或原固件不同，请选择对应参考固件与预设。按每条测量保存参考关系；参考数据随本地工程恢复。

## 配置映射

已知 Enco X4 通过选择／系数代码指纹和当前指针表识别。索引 45 是该适配器的规则，界面和拟合不使用固定索引。配置描述提供预设对应的表内索引、特殊配置、内部状态和输出／区域角色；实际参数地址通过导入文件的指针解析。

未知布局可在“固件详情 → 载入配置映射”读取 JSON。格式为 `{"layout": {...}, "configuration": {...}}`；layout 包含 bank、tables、table_names、profile_count、table_entries、flash_base（均用数值，默认是现有 300 字节／18 槽结构），configuration 包含 adapter、states、presets 和 tables。presets 每项提供 key、title、indices；特殊项提供 special=true 与一个实际索引。tables 每项提供 name、region、output。导入后的映射保存在工程中。候选扫描本身不证明特殊配置的用途。

other/india 对应滤波器在已核对的 112／116／第三方 113 中相同；india 的两个整体增益字段各高 4 dB。调音同时处理两区域，保留各自增益。以后滤波器有差异时仍按每张表的原链分别拟合。

## 剪贴板与工程历史

“复制调音”（Ctrl+Shift+C）保存完整 RAW、PEQ、启用状态和测量／目标／参考关联；“粘贴调音”（Ctrl+Shift+V）支持软件 JSON 和 Flowmix／GraphicEQ 文本。JSON 同时保存在文本和专用剪贴板格式中，可离线转存。参数框里的普通 Ctrl+C/V 保持文本操作。

复制按钮的菜单可复制完整固件预设，包括两路、所有区域、所有状态和整体增益；已有待写入计划时复制计划内容。粘贴时选择目标预设，按目标固件重新定位记录，不携带源固件地址。状态和输出角色不兼容时需改用修正 EQ 重新拟合。目标固件的配置映射、版本等元数据保持目标工程内容。

全局撤销／重做覆盖调音、频响选择、参考关联、固件计划、粘贴与元数据；动作名在工具栏简写，悬停显示全名。一次拖动、一次整体粘贴分别只记一步。曲线显隐和缩放不进入编辑历史，也不会使正在运行的拟合过期。已导出的磁盘文件不会随撤销改变。

工程 v4 保存配置、参考数据和显示选项，兼容 v1/v2/v3。

短屏幕下上方选择区可滚动，曲线显隐始终在主图上方；图形保留可用高度。来源索引与目标库独立加载，目标服务等待不会阻塞自动匹配和测量载入。
